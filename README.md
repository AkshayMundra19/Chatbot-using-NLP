# NLP Chatbot 

An NLP-based intelligent chatbot developed using Python and Flask.  
The chatbot understands user input using Natural Language Processing (NLP) techniques and responds based on trained intents.


## Project Overview

This project demonstrates how Natural Language Processing and Machine Learning can be used to build an interactive chatbot.  
It uses TF-IDF vectorization and Logistic Regression for intent classification and is integrated with a simple web-based user interface.


## Features

- NLP-based text preprocessing  
- Intent classification using Machine Learning  
- Interactive web interface using Flask  
- Supports English and basic Hinglish inputs  
- Clean and modular code structure  
- Beginner & final-year friendly project  


## Technologies Used

- **Python**
- **Flask**
- **NLTK**
- **Scikit-learn**
- **HTML, CSS, JavaScript**
